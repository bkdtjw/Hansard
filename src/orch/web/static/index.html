    adapters

    角色=配置：{角色: {adapter, can_decide, write_scope:[], tools:[], prompt}}。禁止把角色逻辑写死进代码。
    gate_ops
    特权操作命令模板（系统执行器专用）：如 merge_main / run_ci。

    线程默认：max_rounds / loop_limit / chat_ttl。
