字段说明（spec §11.1）

adapters
供应商适配器：{名字: {kind: cli|api|mock, start_cmd, resume_cmd, timeout_s…}}。同一角色可换 adapter 热替换供应商。
roles
角色=配置：{角色: {adapter, can_decide, write_scope:[], tools:[], prompt}}。禁止把角色逻辑写死进代码。
gate_ops
特权操作命令模板（系统执行器专用）：如 merge_main / run_ci。
limits（thread_defaults）
线程默认：max_rounds / loop_limit / chat_ttl。
